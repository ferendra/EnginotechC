# EnginotechC++ — Platform Portability Suite
# ============================================
# Supports: Linux, FreeBSD, OpenBSD, NetBSD, macOS, Windows (MinGW)
#
# Features:
#   - Cross-platform filesystem operations
#   - Platform-specific process management
#   - Terminal color support detection
#   - System information retrieval
#   - Memory info from different OS APIs
#   - Thread utilities
#   - Time management
#   - Network utilities (TCP sockets)
#
# Compilation Targets:
#   - x86_64 (Linux, macOS, Windows)
#   - ARM (Raspberry Pi, embedded Linux)
#   - AArch64 (ARM64 systems)
#   - RISC-V (embedded)
#   - Xtensa (ESP32)
