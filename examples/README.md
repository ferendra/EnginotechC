# EnginotechC++ Examples

This directory contains example programs demonstrating EnginotechC++ features.

## Examples

| Example | Description |
|---------|-------------|
| `hello/` | Hello World program |
| `calculator/` | Simple calculator with basic operations |
| `todo-cli/` | Command-line todo application |
| `http-server/` | Conceptual HTTP server example |

## Running Examples

```bash
# Using the compiler
cd examples/hello
engc build main.ec
./main.exe

# Or using engc run
engc run main.ec
```

## Creating New Examples

1. Create a new directory: `mkdir examples/my-example`
2. Add `main.ec` with your code
3. Optionally add a `README.md` with description
